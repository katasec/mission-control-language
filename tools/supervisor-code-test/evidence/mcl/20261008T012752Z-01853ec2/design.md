API: code/retry_delay.py exposes retry_delay(attempt, base_seconds, max_seconds), a pure function with no side effects. Accept an integer attempt >= 1, excluding bool. Seconds accept Python int and float values, excluding bool; require positivity and finite floats. Reject invalid types or values with ValueError. Keep integer inputs as integers rather than converting them to float, so large finite integers remain valid. Return a numeric delay, retaining the base's numeric type before capping and returning max_seconds when capped.

Algorithm: Validate all three arguments before calculating. If base_seconds >= max_seconds, return the cap immediately. Otherwise start at the base and perform capped doublings for at most attempt - 1 steps. Before each doubling, compare twice the current delay against the cap using exact integer ratios: integers have denominator 1, and finite floats provide as_integer_ratio(). If the next doubling reaches or exceeds the cap, return max_seconds without performing that doubling. Otherwise double the delay and continue. Ratio comparisons use integer arithmetic, avoiding float overflow and lossy conversion of large integers. No power or shift is constructed from the unbounded attempt. Work stops at the cap, so a huge attempt does not cause a huge loop when the numeric bounds are fixed; intermediate integer sizes are bounded by the supplied numeric values.

Failure behaviour: Validation always raises ValueError for invalid input, including invalid seconds even when the base would otherwise immediately reach the cap. No input mutation, sleeping, I/O, logging, or hidden state.

Ownership: This module calculates only the delay. The job runner owns sleeping, retry limits, execution, persistence, and duplicate-side-effect protection. No jitter, dependencies, configuration, network access, or retry framework.

Test matrix: Standard-library unittest tests in code/test_retry_delay.py cover attempt 1 returning the base; attempts 2 and 3 doubling; an exact cap boundary; crossing the cap; base equal to or above the cap; a huge attempt returning the cap; fractional and very small finite floats; large finite integers; floats near their maximum without overflow; and repeatability. Invalid cases cover attempt zero, negatives, floats, strings, None, and booleans; seconds zero, negatives, strings, None, complex values, and booleans; and NaN and both infinities in either seconds argument. Verify ValueError consistently and validation before early returns. Implementation and file creation wait for reviews and approval.
