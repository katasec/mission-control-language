API: code/retry_delay.py exposes the pure function retry_delay(attempt, base_seconds, max_seconds). Accept an integer attempt >= 1, excluding bool. Seconds accept Python int and float values, excluding bool; require positivity and finite floats. Large integers remain valid without float conversion. Invalid input raises ValueError.

Algorithm: Validate every argument before any early return. If base_seconds >= max_seconds, return max_seconds. Represent the base and cap exactly as integer ratios p/q and r/s; integers have denominator 1, and finite floats use as_integer_ratio(). Track the current delay through its numerator, initially p, without performing floating-point doublings. For each requested doubling, compare 2*p*s with r*q. If the next delay reaches or exceeds the cap, return max_seconds. Otherwise double p and continue. Stop after attempt - 1 doublings or upon reaching the cap. No exponentiation or shift uses the unbounded attempt. Iteration count and intermediate integer sizes are bounded by the supplied numeric bounds, not by an arbitrarily large attempt.

Return behaviour: Return the original base on an uncapped first attempt and the supplied max_seconds when capped. For an uncapped integer base, return the exact integer numerator. For an uncapped float base, use math.ldexp(base_seconds, completed_doublings) to obtain the finite float result. If ldexp raises OverflowError, return the exact integer p // q instead: an overflowing power-of-two-scaled finite float necessarily has no fractional part. This prevents infinity, lossy conversion, or arithmetic failure when an integer cap exceeds the float range.

Failure and ownership: Validation consistently raises ValueError, including for invalid seconds when another argument would otherwise trigger an early return. The helper only calculates a delay; it performs no sleeping, execution, persistence, I/O, logging, mutation, or duplicate-side-effect protection. Those responsibilities, along with retry limits, belong to the job runner. No jitter, dependencies, configuration, network calls, or retry framework.

Test matrix: Standard-library unittest tests in code/test_retry_delay.py cover first attempt, doubling, exact and crossed caps, base at or above cap, huge attempts, fractional and subnormal floats, large integers, and floats near their maximum. Include retry_delay(2, 1e308, 10**400) returning the exact finite integer double, further uncapped doublings, and a huge attempt with those bounds returning the cap. Invalid cases cover zero/negative attempts, invalid types and booleans in every position, nonpositive seconds, NaN and both infinities in either seconds argument, and validation before early returns. Check repeatability. Implementation will create code/retry_delay.py and code/test_retry_delay.py only during the build stage.
