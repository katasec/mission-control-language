API: retry_delay(attempt, base_seconds, max_seconds) is a pure numeric function. Accept an integer attempt (including integral subclasses), excluding bool, with attempt >= 1. Accept positive finite real numeric durations: numbers.Real values and decimal.Decimal, excluding bool; reject strings, complex numbers, None and other nonnumeric objects. Invalid inputs raise ValueError before any early cap return.
Algorithm: validate the attempt and convert each accepted duration to fractions.Fraction. This gives exact finite values without converting large integers to float; conversion errors for NaN or infinity become ValueError, and nonpositive fractions are rejected. Start with the base fraction and remaining = attempt - 1. If the base is at or above the cap, return max_seconds. While remaining > 0, compare delay against cap - delay. If delay >= cap - delay, return max_seconds; otherwise double delay and decrement remaining. Return the original base_seconds if attempt == 1 and uncapped; otherwise return the resulting Fraction. The return contract is a real numeric value, with exact rational arithmetic for uncapped doubled values and the original cap object when capped. No exponent or integer proportional to attempt is constructed. Iteration is bounded by the number of doublings between the input base and cap, independently of an arbitrarily huge attempt.
Ownership: the helper owns only validation and delay calculation. The runner owns sleeping, retry limits, job execution, persistence and duplicate-side-effect protection. The helper has no state, jitter, I/O, settings or retry framework.
Test matrix: first attempt (1, 3, 100) -> 3; doubling (2, 3, 100) -> 6 and (3, 3, 100) -> 12; exact/overshot cap (3, 3, 12) -> 12 and (4, 3, 10) -> 10; base >= cap on attempt 1 -> cap; huge attempt 10**100 with base 0.5 and cap 60 -> 60; bool/float/string/None attempt, zero/negative attempt; bool/string/complex/None durations, zero/negative durations, float and Decimal NaN/infinities; fractional base and cap; arbitrarily large integer durations; mixed float/integer/Decimal/Fraction durations. Tests use unittest and numeric equality, and check ValueError for invalid cases.
